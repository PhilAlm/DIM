# Destiny 2 cursor set

These cursors are derived from the first frame of the **Destiny 2 complete Cursor Set** by
HellendenGamer. The original set is available from
<http://www.rw-designer.com/cursor-set/d2fullset> and was released into the public domain.

The source files are animated Windows `.ani` cursors. DIM uses static `.cur` frames because
animated Windows cursors are not reliably supported by modern web browsers. The original hotspot
metadata is preserved.
